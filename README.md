# Kalshi Microstructure — Market Making on Pregame Sports Moneylines

Backtests of four market-making strategies — **Fixed Spread**, **Avellaneda–Stoikov**,
**tabular RL (Spooner et al. 2018)**, and **deep RL (dueling double DQN)** — on
Kalshi's NBA single-game moneyline markets (`KXNBAGAME`), using only data
retrievable from Kalshi's public API. Phase 2 extends the comparison across
NFL/NHL/MLB and time-to-tip regimes.

The interesting part is not "MM in general" but what a **bounded, 1¢-tick,
hours-horizon prediction market** does to the textbook playbook:

| Quirk | Consequence |
|---|---|
| Prices live in [1¢, 99¢] and are probabilities | Local vol must vanish at the bounds: σ(m) ∝ m(100−m). A-S runs on local vol, not constant σ. |
| Tick = 1¢, typical pregame spread = **1¢** | You usually cannot quote inside; queue participation (ρ) drives fills, not price improvement. |
| Horizon = hours to tip, not days | (T−t) in the A-S inventory term is tiny; terminal inventory at tip faces in-game binary swings — flatten or pay. |
| **Maker fees exist** on game series (0.0175·C·P·(1−P) since 07/2025) | ~0.44¢/contract per leg at mid prices vs a 1¢ spread: fees, not edge, dominate naive MM. |
| News (injuries/lineups) lands pregame | Flow and vol concentrate ~8× / ~6× into the final hour; adverse selection is the tail risk. |

## Headline findings (NBA 2024-25 train season; out-of-sample table below)

1. **Naive market making loses money here.** Joining the 1¢ touch both sides:
   spread captured is real (+), but maker fees plus adverse selection
   (inventory PnL ≈ −spread capture) push net PnL deeply negative.
2. **Inventory control is the whole game.** Going naive → inventory-skewed →
   Avellaneda–Stoikov roughly halves the loss twice; A-S holds ~7× less
   inventory than naive at the same quote sizes.
3. **The fee model is decisive.** With maker fees set to zero the same naive
   strategy flips sign. Any Kalshi MM analysis that ignores the 2025 maker-fee
   change is fiction.
4. **RL's job is selectivity** — learning *when* to quote at all, one-sided
   quoting against flow, and flattening before tip. The reward must be
   asymmetrically dampened (Spooner's ψ) or the agent learns to trend-ride
   inventory instead of making markets.

*(Final out-of-sample 2025-26 comparison table + figures are generated by
`scripts/03_run_backtests.py` into `results/`.)*

## Data

Kalshi's API provides **no historical order book**. What it does provide
(all unauthenticated):

- **1-min candlesticks** including bid/ask OHLC → minute-level NBBO
- the full **trade tape** (price, fractional size, taker side, timestamp)
- market/event metadata (no scheduled start time — tip is inferred from the
  data: first sustained burst of minute-level mid movement before close,
  validated within ~10 min of true tips; fallback close − typical duration)

A **websocket recorder** (`scripts/00_record_lob.py`) captures live
`orderbook_delta` + `trade` for active game markets across all four sports —
the growing real-LOB dataset validates the fill model's ρ and λ(δ) and feeds
depth features to the deep RL agent in phase 2. (Requires an API key:
kalshi.com → Settings → API; drop the key id in `secrets/kalshi_key_id.txt`
and the RSA private key in `secrets/kalshi_private_key.pem`.)

## Fill model (the part to be skeptical about)

Backtesting maker strategies without book data means simulating the
counterfactual "would my quote have been filled?". Two layers:

**Layer 1 — tape-anchored (deterministic, conservative).** Every historical
trade is routed against the counterfactual book = historical NBBO + our quote:
- trade strictly **through** our price → full fill (the whole queue cleared);
- trade **at** our price while we join the touch → fill ρ·size
  (ρ = queue-participation, default 0.5, sensitivity reported);
- trade at/behind the old touch while we quote **inside** it → we were first
  in queue → full fill.
Layer 1 never invents volume and inherits real adverse selection: fills occur
at the moments real flow arrived, and the subsequent price path is real.

**Layer 2 — latent demand (stochastic, optional).** Quoting tighter than
history attracts flow that never printed. Arrivals are Poisson with the
touch-anchored intensity λ(d) = R·e^(−k_out(d−0.5)) calibrated per
hours-to-tip bucket (R identified by the tape; ~80% of trades print at the
touch so k_out comes from the through-trade tail). *Inside* the touch the
elasticity is an explicit capped assumption (k_in: one tick ≈ doubles flow),
never an extrapolation. Only the incremental intensity vs the historical
touch is added (no double counting), capped at 25% of game tape volume.

Headline numbers are reported **tape-only** (lower bound); latent mode is the
central estimate. Known limitation either way: our quotes don't move the
historical price path (no impact model).

## Strategies

- `fixed_spread` — quote mid ± s/2, optional linear inventory skew. Baseline.
- `avellaneda_stoikov` — reservation price r = m − qγσ²(T−t), half-spread
  γσ²(T−t)/2 + (1/γ)ln(1+γ/k), with T = tip, σ = bounded local vol, k from
  the calibrated intensity; tick rounding; no quotes within 3¢ of the bounds.
- `spooner_rl` — SARSA(λ) over hashed tile codings of (inventory, spread,
  time-to-tip, signed flow, vol, |mid−50|); 13 actions (offset ladder incl.
  improving, one-sided, no-quote, taker clear); reward
  **ψ = ΔPnL − max(0, η·inv·Δmid)** — the asymmetric dampening that strips
  trend-riding gains — learned online inside the engine.
- `drl` — gymnasium env over the same engine; observation = (32, 8) stacked
  history frames (stand-in for book depth); temporal-conv dueling double DQN
  with n-step returns on CUDA; **pluggable reward module**
  (raw ΔPnL / quadratic inventory penalty / Spooner ψ, ± terminal |inv|
  penalty) → reward ablations are a first-class experiment.

All four run through the identical engine, fee schedule, and fill model;
identical action ladder for both RL agents.

## Reproduce

```bash
pip install -e ".[dev]"            # torch (CUDA) installed separately
python scripts/01_download.py --sport nba --season 2024-25   # ~1-2 h, resumable
python scripts/01_download.py --sport nba --season 2025-26
python scripts/02_calibrate.py --sport nba --season 2024-25
python scripts/04_train_spooner.py --season 2024-25
python scripts/05_train_drl.py --season 2024-25 --reward spooner
python scripts/03_run_backtests.py --season 2025-26 --calib-season 2024-25 \
    --strategies fixed_spread fixed_spread_skew as spooner drl
pytest -q                          # 31 tests: fees, fills, accounting identity
```

Protocol: calibrations and RL policies are fitted on **2024-25** only;
**2025-26** is untouched until the final comparison.
